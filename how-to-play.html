How to Play

Everything you need to install the modpack and join the MC Project server.

SETUP

Get Started

01
INSTALL

Download Modrinth

Install the Modrinth App. This is the easiest way to install and manage the modpack.

Download Modrinth
02
MODPACK

Install the Modpack

Open the modpack using the link below. Modrinth will handle the required mods and files.

Open Modpack

Make sure you're using Minecraft 1.21.1 with the NeoForge version provided by the pack.

03
SERVER

Join the Server

Launch the modpack, open Multiplayer, and add the server using the address below.

SERVER ADDRESS YOUR.SERVER.ADDRESS

The server needs to be online before you can connect.

04
BEFORE YOU PLAY

Extra Settings & Tips

Shaders

If you're using Complementary Shaders, enable them through Iris after launching.

Voice Chat

Simple Voice Chat uses your microphone for proximity-based communication.

Claims

Use Open Parties and Claims to protect your builds and manage shared areas.

Performance

Distant Horizons and shaders can be demanding. Lower your render distance if performance suffers.
