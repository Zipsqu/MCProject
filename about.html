MODPACK

What's Included

🏗️
BUILDING

Building & Decoration

Handcrafted

Adds a large selection of decorative furniture and building blocks.

Create

Adds mechanical machinery, automation, contraptions, transportation and engineering-focused building.

Create: Copycats+

Adds copycat blocks that let Create machinery and contraptions blend into custom builds.

Create Crafts & Additions

Expands Create with electrical systems, energy generation, automation and additional crafting options.

WorldEdit

Provides powerful tools for rapidly creating, editing and transforming large areas of the world.

Tectonic

Overhauls terrain generation to create more dramatic mountains, valleys and large-scale landscapes.

🚂
TRANSPORTATION

Vehicles & Transportation

Create: Steam 'n' Rails

Expands Create's railway system with new trains, tracks, signals and railway infrastructure.

Small Ships

Adds controllable sailing ships for travelling across oceans and other large bodies of water.

Simple Planes

Adds craftable planes that provide another way to travel through the Minecraft world.

🔫
COMBAT

Weapons & Combat

Vic's Point Blank

Adds firearms and shooting mechanics, bringing ranged combat and weapon-based gameplay to Minecraft.

🎒
STORAGE

Storage & Inventory

Sophisticated Backpacks

Adds upgradeable backpacks with expanded storage, sorting features and useful inventory upgrades.

Sophisticated Storage

Adds customizable storage blocks with upgrades for sorting, organization and increased capacity.

🌍
EXPLORATION

World Generation & Exploration

Terralith

Overhauls the Overworld with a wide variety of new biomes, terrain formations and landscapes.

Tectonic

Reshapes the world's terrain with larger mountains, deeper valleys and more dramatic geographical features.

Distant Horizons

Renders simplified terrain at long distances, allowing you to see much farther across the world.

🗺️
NAVIGATION

Maps & Navigation

Xaero's Minimap

Adds a minimap with useful navigation features, waypoint markers and nearby terrain information.

Xaero's World Map

Provides a detailed world map that reveals explored terrain and helps you navigate across long distances.

BlueMap

Generates a 3D map of the Minecraft world that players can explore through a web browser.

BlueMap: FTBChunks

Integrates FTB Chunks claim information into BlueMap, helping players view claimed areas on the world map.

🛡️
MULTIPLAYER

Claims & Multiplayer

FTB Chunks

Lets players claim chunks, protect their builds and manage territory on multiplayer servers.

FTB Teams

Allows players to form teams and share team-based features across supported FTB mods.

🧭
UTILITY

Utility & Information

AppleSkin

Displays additional hunger and saturation information to help players understand their food and regeneration.

Jade

Displays information about blocks and entities when you look at them in the game.

EMI

Provides an item and recipe viewer for looking up crafting recipes and uses for items.

GraveStone Mod

Creates a gravestone when a player dies, helping preserve their items for later recovery.

Mouse Tweaks

Improves inventory management with more convenient mouse controls for moving and sorting items.

⚡
PERFORMANCE

Performance & Optimization

Concurrent Chunk Management Engine (C2ME)

Optimizes chunk generation and loading through concurrent processing to improve world performance.

FerriteCore

Reduces memory usage by optimizing how Minecraft stores and manages data.

ModernFix

Improves performance, reduces memory consumption and fixes a variety of Minecraft issues.

Lithium

Optimizes game logic to improve performance without changing the core gameplay experience.

Chunky

Pre-generates world chunks to reduce exploration-related lag and help server performance.

ImmediatelyFast

Optimizes immediate-mode rendering to improve client-side performance and frame rates.

Entity Culling

Skips rendering entities and block entities that are hidden from view to improve frame rates.

🎨
VISUALS

Visual Enhancements

Iris Shaders

Adds support for shader packs, allowing players to customize Minecraft's lighting and visual effects.

Complementary Shaders — Reimagined

Enhances lighting, shadows, water and atmospheric effects with a refined visual style.

PrettyRealistic PBR

Adds high-resolution textures and physically based rendering details for a more realistic appearance.

⚙️
LIBRARIES

Dependencies & Libraries

Architectury API

Provides a cross-platform API used by other mods to support multiple mod loaders.

Curios API

Provides an accessory-slot system that allows compatible mods to add wearable equipment slots.

FTB Library

Supplies shared code and functionality required by several mods in the FTB ecosystem.

GeckoLib

Provides advanced animation tools used by compatible mods for animated models and entities.

Kotlin for Forge

Adds Kotlin language support for mods that depend on the Kotlin runtime.

Lithostitched

Provides world-generation utilities and shared systems used by compatible biome and terrain mods.

Resourceful Lib

Provides shared utilities and code required by mods built around the Resourceful ecosystem.

Sophisticated Core

Provides shared features and systems required by Sophisticated Backpacks and Sophisticated Storage.

FTB Chunks x Xaero's Compatibility

Connects FTB Chunks with Xaero's maps to display compatible claim and team information.
