
## Current Mods

### 🌍 World Generation

| Mod               | Purpose                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| **Tectonic**      | Overhauls terrain generation with larger mountains, valleys, cliffs and more dramatic landscapes. |
| **Terralith**     | Adds a large variety of new Overworld biomes and terrain using Minecraft's existing blocks.       |
| **Lithostitched** | World-generation library required by supported terrain/worldgen mods.                             |

### 🏗️ Engineering & Railways

| Mod                 | Purpose                                                                                                  |
| ------------------- | -------------------------------------------------------------------------------------------------------- |
| **Create**          | Adds mechanical power, automation, factories, machines, contraptions, logistics and engineering systems. |
| **Steam 'n' Rails** | Expands Create's railway and train systems with additional rail and train functionality.                 |

### 🔭 Rendering & Graphics

| Mod                          | Purpose                                                                                                            |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Sodium**                   | Major rendering optimisation designed to improve Minecraft's graphical performance.                                |
| **Distant Horizons**         | Generates simplified distant terrain so the player can see vastly farther than normal Minecraft render distance.   |
| **Iris Shaders**             | Shader loader allowing Minecraft to use modern shader packs.                                                       |
| **Complementary Reimagined** | High-quality shader pack providing enhanced lighting, shadows, atmosphere, clouds, water and other visual effects. |

### 🗺️ Navigation

| Mod                 | Purpose                                              |
| ------------------- | ---------------------------------------------------- |
| **Xaero's Minimap** | Provides an in-game minimap and navigation features. |
