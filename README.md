# Minecraft Server — Modpack

Minecraft Java Edition **1.21.1**
Mod Loader: **NeoForge**

This modpack is focused on:

* 🌍 Dramatic and varied world generation
* 🏗️ Create-based engineering and automation
* 🚂 Advanced railway systems
* 🔭 Extremely long-distance terrain rendering
* ✨ High-quality shaders and atmosphere
* ⚡ Performance optimisation
* 🗺️ Useful navigation tools

---

## Current Mods

### 🌍 World Generation

| Mod               | Purpose                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| **Tectonic**      | Overhauls terrain generation with larger mountains, valleys, cliffs and more dramatic landscapes. |
| **Terralith**     | Adds a large variety of new Overworld biomes and terrain using Minecraft's existing blocks.       |
| **Lithostitched** | World-generation library required by supported terrain/worldgen mods.                             |

### 🏗️ Engineering & Railways

| Mod                 | Purpose                                                                                                  |
| ------------------- | -------------------------------------------------------------------------------------------------------- |
| **Create**          | Adds mechanical power, automation, factories, machines, contraptions, logistics and engineering systems. |
| **Steam 'n' Rails** | Expands Create's railway and train systems with additional rail and train functionality.                 |

### 🔭 Rendering & Graphics

| Mod                          | Purpose                                                                                                            |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Sodium**                   | Major rendering optimisation designed to improve Minecraft's graphical performance.                                |
| **Distant Horizons**         | Generates simplified distant terrain so the player can see vastly farther than normal Minecraft render distance.   |
| **Iris Shaders**             | Shader loader allowing Minecraft to use modern shader packs.                                                       |
| **Complementary Reimagined** | High-quality shader pack providing enhanced lighting, shadows, atmosphere, clouds, water and other visual effects. |

### 🗺️ Navigation

| Mod                 | Purpose                                              |
| ------------------- | ---------------------------------------------------- |
| **Xaero's Minimap** | Provides an in-game minimap and navigation features. |

---

## Current Visual Stack

The graphical system currently consists of:

**Sodium**
→ rendering optimisation

**Iris**
→ shader support

**Complementary Reimagined**
→ lighting, shadows, atmosphere and visual effects

**Distant Horizons**
→ extreme viewing distance

**Tectonic + Terralith**
→ detailed and dramatic terrain generation

The current pack does **not yet include a dedicated high-resolution resource pack**.

## Design Goal

The aim is to create a Minecraft experience that feels like:

> **Vanilla Minecraft evolved into a large-scale engineering and exploration game.**

The world should have dramatic terrain, long viewing distances, high-quality lighting and materials, while remaining practical for multiplayer and reasonably performant on mid-range gaming hardware.
