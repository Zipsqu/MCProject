Optimises Minecraft's rendering engine to significantly improve client-side performance and frame rates.

Lithium

Optimises Minecraft's game logic to improve performance without changing the core gameplay experience.

FerriteCore

Reduces Minecraft's memory usage through optimisations to how game data is stored.

ModernFix

Provides a broad collection of performance, memory, loading-time and stability improvements.

ImmediatelyFast

Optimises immediate-mode rendering to improve performance when drawing Minecraft's interface and world elements.

Concurrent Chunk Management Engine (C2ME)

Improves chunk generation, loading and processing by making greater use of concurrent processing.

Prevents the game from rendering entities that are hidden from view, improving rendering performance.

Extends the visible world far beyond normal render distance using a level-of-detail system.
